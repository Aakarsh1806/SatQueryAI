# Grounding sanity-check overlays

Generated by `scripts/eval_model2.py`: green = reference absolute-pixel box,
red = model prediction at box threshold 0.3 / text threshold 0.25. Predicted
scores are uncalibrated. The legend is below the original image; coordinates
are unchanged. See ../model2_eval.md for every prompt, IoU and empty detection.

These images contain VRSBench validation pixels and are academic-use local
artifacts. PNGs are Git-ignored; do not commit or redistribute dataset pixels.
